# 猫奏乐团 · Cat Cadenza

竖屏音乐割草试玩：三章十五关，走位拾取乐器，鼓声与攻击共用节拍。

按住舞台并拖动手指移动小猫，松手立即停下；轻点或重按不会使小猫跳到点击位置。电脑支持 WASD。点击“开始”开启声音。

index.html 是包含全部图片、音色和脚本的独立游戏文件。GitHub Pages 发布后，玩家无需 GitHub 账号即可打开网页。进度保存在当前浏览器，不同网址、浏览器和设备分别保存。

音乐以项目原创组曲为主，后期关卡引用少量经典动机；来源与许可见游戏内说明和 NOTICE.txt。引用《春》的音乐编配与谱数据沿用 CC BY-SA 3.0，其它代码和资源各自沿用相应说明，不对整仓库另行授予统一许可证。

复活和加奖为明确标注的广告流程测试，未接入真实广告。当前是浏览器游戏，尚非微信原生小游戏。
