# 猫奏乐团 · Cat Cadenza

竖屏音乐割草试玩：三章十五关，走位拾取乐器，鼓声与攻击共用节拍。

按住舞台并拖动手指移动小猫，松手立即停下；轻点或重按不会使小猫跳到点击位置。电脑支持 WASD。点击“开始”开启声音。

index.html 是包含全部图片、音色和脚本的独立游戏文件。GitHub Pages 发布后，玩家无需 GitHub 账号即可打开网页。进度保存在当前浏览器，不同网址、浏览器和设备分别保存。

三章分别采用《卡农》《土耳其进行曲》《春》的游戏演奏编配，每首提供 128 拍的选段及章内乐句变化。来源、改编范围与许可见游戏内说明和 NOTICE.txt；《卡农》的谱源遵循 CC BY 3.0，《春》的音乐编配与谱数据沿用 CC BY-SA 3.0，其它代码和资源各自沿用相应说明，不对整仓库另行授予统一许可证。

第一章逐步加入鼓、贝斯（1-2）、钢琴（1-3）、吉他（1-4）；第二章加入小提琴（2-1）和大提琴（2-3）；第三章加入长笛（3-1）和竖琴（3-3）。新乐器在对应关卡中试用，首次通关后永久解锁，可培养并带回旧关。每局使用鼓加两件副乐器，首次试用会预留一个位置。

复活和加奖为明确标注的广告流程测试，未接入真实广告。当前是浏览器游戏，尚非微信原生小游戏。
